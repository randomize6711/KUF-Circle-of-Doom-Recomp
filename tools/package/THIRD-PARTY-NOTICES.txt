Kingdom Under Fire: Circle of Doom Recomp - third-party software in this package

This project's own work is under the MIT licence: licenses/PROJECT-LICENSE.txt, and what that covers:
licenses/PROJECT-NOTICE.txt. This package contains no code or data of the game; bin/kuf_cod is made on the player's machine (docs/LOCAL_BUILD.md).
The programs in bin/ and builder/ are built with the ReXGlue SDK (https://github.com/rexglue/rexglue-sdk, BSD-3-Clause,
portions derived from the Xenia project; licenses/rexglue-sdk-LICENSE) and the open-source software below, compiled
into bin/librexruntimerd.so, bin/librexgpu-xenosrd.so and builder/lib unless noted. Each licence text is in licenses/
under the file name given.

Source: the release assets kuf-cod-recomp-<version>-source.tar.xz (this project and the SDK with its submodules, exactly
as built: the project's patches applied, console keys removed) and kuf-cod-recomp-<version>-toolchain-sources.tar. They
are published with each release, next to the binaries.

The setup AppImage additionally contains the setup program (this project; GTK and GLib are used from your system,
not bundled; its C++ library is linked in under the GCC Runtime Library Exception), the Cinzel font (Copyright 2020 The
Cinzel Project Authors, SIL Open Font License 1.1: assets/fonts/Cinzel-OFL.txt) and the AppImage runtime, release 20251108
(https://github.com/AppImage/type2-runtime, MIT). That runtime statically links libfuse 3.15.0 (LGPL 2.1, text in
licenses/FFmpeg-COPYING.LGPLv2.1), squashfuse 0.5.2 (BSD-style), and permissively licensed zstd, zlib, mimalloc and musl.
The sources of the runtime, libfuse and squashfuse are in the toolchain-sources asset. To use a modified libfuse, rebuild
the runtime from them and replace the runtime at the start of the AppImage (the setup's files are appended to it).
